# UNIVERSAL WEBSITE UX/UI EVALUATION HANDBOOK
## Enterprise-Grade Framework for Evaluating Any Website

Version: Final Edition

---

# 1. PURPOSE

Framework ini dirancang untuk mengevaluasi:

- Landing Page
- Company Website
- Portfolio Website
- SaaS Product
- Dashboard & Analytics Platform
- E-Commerce Website
- Educational Platform
- Government Website
- Internal Enterprise Systems
- AI Products
- Mobile Web Applications

Tujuan:

- Menilai kualitas UX/UI secara objektif
- Mengidentifikasi masalah prioritas tinggi
- Membandingkan beberapa website
- Menentukan readiness level sebelum deployment

---

# 2. EVALUATION METHODOLOGY

Gunakan kombinasi:

### A. Scoring Rubric (1–5)

| Score | Meaning |
|---------|---------|
| 1 | Critical Problems |
| 2 | Below Standard |
| 3 | Acceptable |
| 4 | Professional |
| 5 | Best-in-Class |

### B. Pass / Fail Checklist

Setiap item harus diverifikasi.

### C. Severity Rating

| Severity | Impact |
|-----------|---------|
| Low | Cosmetic |
| Medium | Noticeable Friction |
| High | Major UX Impact |
| Critical | Business Risk |

# 3. VISUAL DESIGN & AESTHETICS (10%)

## Evaluation Criteria

### Visual Hierarchy

Checklist:

- [ ] Primary CTA immediately visible
- [ ] Important content receives highest visual emphasis
- [ ] Eye flow follows intended user journey
- [ ] No competing focal points

### Visual Balance

- [ ] Consistent alignment
- [ ] Balanced visual weight
- [ ] No cluttered sections

### Brand Expression

- [ ] Professional appearance
- [ ] Consistent visual identity
- [ ] Trustworthy presentation

### Common Failures

- Too many colors
- Too many CTA buttons
- Decorative clutter
- Inconsistent imagery

# 4. TYPOGRAPHY & READABILITY (10%)

## Standards

### Body Text

Recommended:

- 16–20px
- Line-height 1.4–1.8

### Hierarchy

- [ ] H1 clear
- [ ] H2 clear
- [ ] H3 clear
- [ ] Body text distinguishable

### Readability

- [ ] Comfortable line length
- [ ] Adequate spacing
- [ ] Easy scanning

### Common Failures

- Tiny text
- Excessive font families
- Long paragraphs
- Weak hierarchy
